Remote97 把你手边的手机或电脑变成家庭影院的万能遥控器。它通过家庭局域网直接连接你的设备 — 不需要 Control4 那样的控制主机，不需要专业安装，也没有月费。

## 亮点

- **无需主机、无需额外硬件** — 以 App 形式运行在你已有的设备上，通过局域网直连影音设备。
- **自动发现** — 自动找到局域网里支持的设备，无需手动输入 IP。
- **一个遥控器全搞定** — 音量、信号源、电源、声场模式、均衡器、屏幕文字输入，全部集中在一处。
- **多房间音乐** — 把 Sonos、Bluesound（BluOS）、WiiM、Arylic 音箱组成分组，多房间同步播放。
- **随心定制** — 按家庭 / 房间整理设备，多种界面主题（玻璃质感、水墨风等）任你选择。
- **Windows 全局快捷键** — 坐在座位上用键盘掌控整套系统。
- **隐私优先** — 无云端、无账号、无遥测。一切数据都留在你的局域网内。
- **免费。**
