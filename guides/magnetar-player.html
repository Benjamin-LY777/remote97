Media player

Control a MAGNETAR 4K player from your phone

The MAGNETAR UDP800 MKII and UDP900 MKII expose a plain text control port on TCP 8102. Remote97 speaks it directly — no IR blaster, no hub, no manufacturer cloud app.

6 min read · MAGNETAR UDP800 MKII / UDP900 MKII · 麦尼塔

MAGNETAR (麦尼塔) UDP800 MKII and UDP900 MKII are 4K UHD Blu-ray / SACD universal players. Their manual documents a "Network Control" interface: a plain TCP socket on port 8102 that accepts the same three-character commands as the RS-232 port, each frame terminated with \r\n, answered with ack. Remote97 uses that interface to give you a real on-screen remote, with the same commands the official remote sends.

What you can control

  • Power and disc — power toggle / on / off, eject the tray, front-panel dimming and pure-audio mode.
  • Playback and navigation — play, pause, stop, previous/next, fast forward/backward, D-pad, confirm, back, home and menu.
  • Number and colour keys — 0–9, clear, go-to, and the four coloured keys for interactive disc menus.
  • AV options — audio track, subtitle, angle, zoom, repeat, A-B repeat, picture-in-picture, output resolution and HDR selection.
  • Step volume and mute — the protocol offers step-up / step-down / mute only; Remote97 does not pretend there is an absolute volume slider.
  • Wake-on-LAN power-on — from network standby, Remote97 sends a WoL magic packet before the power command. See the WoL guide.

What the protocol does not offer

Honest limits. There is no source-input selection and no absolute volume or volume query in this protocol — those belong to a different player family. Remote97 will not put fake controls on the page. State is tracked locally from the commands you send and from optional status pushes, so it is an estimate, not a guaranteed readout.

The player also allows only one control connection at a time. If another remote or app is connected, commands can be dropped. Remote97 keeps a single long-lived connection per device and spaces commands out, which matches the player's real behaviour.

Set it up

1

Enable the player's network interface

Give the player a wired LAN connection and set a static IP or DHCP reservation. The control port is fixed at TCP 8102.

2

Switch to Network Standby if you want power-on

In the player's standby-mode setting choose Network Standby. In the default energy-saving standby the player will not wake from an IP command. Note its MAC address — Remote97 needs it for the WoL packet.

3

Install Remote97

Get it from the download page on a phone on the same network.

4

Add the player

Remote97 probes for the MAGNETAR signature and port 8102. If discovery misses it, add it manually by IP and enter the MAC address so wake-on-LAN works.

5

Allow a few seconds after wake

Real players can take around 30 seconds after power-on before they accept commands. If a scene chains a wake with a playback command, add a short delay.

Troubleshooting

  • Cannot add from standby: turn the player on first — the control port does not answer in energy-saving standby.
  • Power-on command ignored: you are in energy-saving standby. Switch to Network Standby and confirm the MAC address is set so WoL can be sent.
  • Commands fail intermittently: another app or remote is probably holding the single control connection. Close it and retry.
  • Volume or input controls missing: expected — the protocol does not expose them. Use the player's own remote for those functions.
