Media player

Control a Zidoo or VidOn media player from your phone

High-end media players are built for a big screen, not for hunting through a movie library with a six-button remote. Remote97 uses their local network control APIs to put navigation, playback and app launching on your phone.

6 min read · Zidoo / 芝杜 · VidOn / Egreat · Android, Windows & iOS

These players expose different but equally local interfaces:

  • Zidoo — an HTTP API on port 9529. Endpoints include ZidooControlCenter/getModel, ZidooControlCenter/RemoteControl/sendkey?key=, .../inputtext?key=, Apps/getAppList, Apps/openApp, Player/getPlayStatus and ZidooMusicControl/v2/setPowerOption. Responses are JSON.
  • VidOn / Egreat — a TCP control service on port 33080 with case-sensitive frames in the form CMD,<keycode>,END. A separate web console and app icons live on HTTP 34080.

Neither family broadcasts SSDP or mDNS reliably, so Remote97 actively probes 9529 / 33080 on the chosen subnet and also supports manual IP add.

What you can control

  • Full navigation — D-pad, select, back, home, menu and number keys.
  • Playback — play / pause, stop, next / previous, seek where the player exposes it, plus playback-state queries.
  • Text input — send a search string or filename to the player instead of typing with a cursor.
  • Apps — list installed apps and launch one by package name on Zidoo.
  • Power — standby / power-off / reboot options on Zidoo's power endpoint.

Set it up

1

Enable network control on the player

On Zidoo this is the "Control Center" / 中控 option in settings; on VidOn check the network control service. Without it the ports stay closed.

2

Reserve an IP address

Players often sit behind a wired switch — a DHCP reservation avoids re-adding the device later.

3

Install Remote97 and join the same LAN

Download from the download page.

4

Discover or add by IP

Let the directed scan find the player, or enter the IP manually if your network filters probes.

Honest limitations

Deep power-off is not wakeable. If the player physically cuts power to its network interface, no LAN command can bring it back. Keep the original remote or use the front-panel button for a cold start.

These are vendor-specific APIs, not a universal standard: key names differ between Zidoo and VidOn, and some "best-effort" keys are simply ignored by firmware that does not implement them. The app sends them harmlessly rather than pretending the function exists.

Troubleshooting

  • Port closed: re-check the player's network-control toggle and reboot the player.
  • Keys ignored: the firmware may not implement that specific key code; navigation and playback keys are the reliable subset.
  • App list empty: the Zidoo Control Center service must be running; open it once on the player.
  • Appears as an unknown device: use manual add and pick the correct family so commands are encoded for the right protocol.
