TV

Control a Xiaomi or Redmi TV from your phone

A lost Mi TV remote does not have to mean a dead TV. Remote97 sends the same local HTTP key events that control-center drivers use — straight over your WiFi, with no infrared hardware.

6 min read · Xiaomi TV / Redmi TV / Mi TV · Android, Windows & iOS

Xiaomi and Redmi televisions expose a small HTTP control service on TCP 6095. Endpoints such as /controller?action=keyevent accept key codes, /controller?action=changesource switches inputs, and /request?action=isalive reports whether the set is reachable. Remote97 wraps those endpoints in a normal remote-control interface.

Unlike AV receivers and streamers, these TVs generally do not broadcast SSDP or mDNS. That matters: discovery has to actively probe local addresses on 6095, or you add the TV's IP by hand.

What you can control

  • Navigation — up / down / left / right, select, back, home and menu key events.
  • Volume — read the current level from /general?action=getVolum and change it with key events.
  • Inputs — switch to HDMI 1 / HDMI 2 and other sources exposed by the set.
  • Apps — launch an installed app by package name via startapp.
  • Power off — send the standby key when you are done watching.

Set it up

1

Install Remote97 on your phone or PC

Available on the download page.

2

Put both devices on one LAN

The TV must be on the same subnet. Guest networks, mesh AP isolation and VPN tunnels commonly break the probe.

3

Enable network/remote control on the TV

On some firmware the HTTP control service is off until the TV's remote-control / 中控 setting is enabled. Check Settings → Network or the TV's control options.

4

Discover or add by IP

Remote97 scans local addresses for port 6095. If nothing appears, use manual add with the TV's IP (find it in the TV's network settings or your router's client list).

The honest limitations

It can turn the TV off, but not on. In standby the WiFi module powers down, so there is no network endpoint to wake. Wake-on-LAN and BLE wake paths were investigated and are not supported — keep the physical remote (or the TV's own power button) for power-on.

Control is local only: you cannot operate the TV from outside the home, and there is no cloud relay. The app also does not guess credentials — if the TV firmware requires per-device authorisation, you authorise it once on the TV itself.

Troubleshooting

  • Scan finds nothing: add the IP manually. These TVs are silent on the network by design.
  • IP works once then stops: reserve a DHCP lease for the TV in your router.
  • Keys do nothing: confirm the TV's network remote-control setting, then power-cycle the TV.
  • Volume reads but does not change: some models only accept volume key events while an input is active.
