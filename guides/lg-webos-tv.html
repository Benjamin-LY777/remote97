TV

Control an LG webOS TV from your phone (no IR blaster)

Lost the Magic Remote, or just tired of hunting for it? Remote97 talks to LG webOS TVs directly over your home network using the same SSAP interface that LG's own tooling uses.

6 min read · LG webOS / OLED / QNED · Android, Windows & iOS

webOS TVs expose a local control interface called SSAP (Simple Service Access Protocol) on a WebSocket at TCP 3000. Remote97 opens that socket, sends a hello, completes a one-time pairing handshake, and then speaks JSON requests such as ssap://audio/setVolume and ssap://tv/switchInput. Nothing goes through a cloud service — the phone and the TV talk across your LAN.

What you can control

Once paired, the TV treats the app as a registered client:

  • Volume and mute — absolute level, up/down and mute state, with the TV's real value read back.
  • Inputs — enumerate the external input list and switch between HDMI ports, antenna and component inputs.
  • Apps — list installed apps and launch one directly (Netflix, YouTube, Plex, a media server app).
  • Navigation — D-pad, select, back, home, channel and media transport keys.
  • Pointer and text — webOS offers a second pointer input socket, which is what makes an on-screen cursor and keyboard practical.
  • Power off and power state — send the standby command and query current power state.

Set it up in four steps

1

Install Remote97

Get it from the download page — Android, Windows and iOS are supported.

2

Join the same network

Phone and TV must be on the same LAN / VLAN. Guest WiFi and AP isolation will block discovery.

3

Let it discover, or add the IP manually

Remote97 probes port 3000 on local addresses. If the TV does not advertise itself, use manual add and type the TV's IP address.

4

Accept the pairing prompt on the TV

webOS shows a one-time consent dialog. Accept it and the pairing key stays on your device — no account is created.

The honest limitations

Power-on is the weak spot. When a webOS TV is fully off, its network stack usually sleeps, so a Wake-on-LAN style command is not reliable. Keep the physical remote handy for the first power-on, or enable the TV's quick-start / always-connected option if your model offers one.

Remote97 is a WiFi remote, not an infrared blaster: there is no line-of-sight requirement between devices, but the TV must be reachable on the network at the moment you send a command. It also cannot reach the TV from outside your home network — that is a deliberate consequence of the no-cloud design, not a missing feature.

Troubleshooting

  • iOS finds nothing: check that the Local Network permission is enabled in iOS Settings. Remote97 asks for it on first use.
  • Pairing prompt never appears: reboot the TV, then remove and re-add the device in Remote97 to restart the register handshake.
  • Works once, then stops: the TV may have renewed its DHCP lease. Re-run discovery or add the new IP.
  • Inputs show but do not switch: some models require the input list subscription to be refreshed after an HDMI handshake. Re-open the device detail page.
