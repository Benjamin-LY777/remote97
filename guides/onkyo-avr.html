AV receiver

Control an Onkyo AVR from your phone with eISCP

Onkyo receivers have had a documented network control protocol for years. Remote97 speaks it locally, so you get real volume, input and power feedback instead of a one-way IR blast.

6 min read · Onkyo / Integra TX-NR, TX-RZ · Android, Windows & iOS

Onkyo (and its Integra sibling) use ISCP / eISCP — Integra Serial Control Protocol wrapped for Ethernet — on TCP/UDP 60128. Each eISCP frame is a 16-byte header followed by an ASCII command such as MVLUP or SLI26. The receiver replies with the actual resulting state, which is why the app can show a real volume level rather than an optimistic guess.

What you can control

  • Power — on / standby with state read back.
  • Volume and mute — absolute level, step up/down, mute toggle.
  • Input selection — the receiver's full selector list (HDMI, optical, phono, network, Bluetooth).
  • Listening modes — stereo, Dolby / DTS variants and the receiver's own presets.
  • Second zone — on models that support it, Zone 2 power/volume/source are separate commands.

Set it up

1

Enable Network Standby

On the receiver: Setup → Hardware / Network → Network Standby. The eISCP listener must survive standby.

2

Install Remote97 on the same LAN

Get it from the download page.

3

Discover or add the IP

Remote97 probes port 60128 across the selected subnet; manual IP add works too when multicast is filtered.

4

Use status feedback

Because eISCP answers with the resulting state, volume and input shown in the app stay in sync with the front panel.

Honest limitations and troubleshooting

First power-on needs the real remote. A receiver in deep standby has no live network stack. Network Standby keeps it reachable for subsequent commands, but the initial power-on after a full unplug is a hardware action.
  • Not discovered: reserve a DHCP lease, or add the IP manually; check that no VPN app is stealing the local route.
  • Commands time out: confirm the receiver's "Network Control" / "Control via IP" option is enabled.
  • Inputs look wrong: the selector list is read from the receiver; re-open the device page after changing HDMI assignments.
