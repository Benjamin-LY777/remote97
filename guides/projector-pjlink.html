Projector

Control a PJLink projector over the network from one app

Ceiling-mounted projectors are the worst devices to point a remote at. PJLink gives them a wired-network control port instead — Remote97 turns that into power, input and mute buttons on your phone.

7 min read · Epson / Sony / Panasonic / BenQ / JVC / Optoma / NEC / ViewSonic

PJLink is a JBMIA standard for controlling projectors over TCP, normally on port 4352. The projector greets the client with PJLINK 0 <random>\r, then accepts CR-terminated commands such as %1POWR 1\r (power on), %1INPT 32\r (input) and %1POWR ?\r (query). Class 2 adds authentication and status queries such as lamp hours.

Remote97 implements the standard class-independent command set, so it works with Epson, Sony, Panasonic, BenQ, JVC, Optoma, NEC, ViewSonic and other projectors that speak PJLink — not just one brand.

What you can control

  • Power — on / off plus a real power-state query (warming, cooling, standby).
  • Input switching — RGB / PC, video, HDMI 1 / HDMI 2 and the projector's other sources. On an Epson EH-TW9400, for example, the real codes are PC=11, HDMI1=32, HDMI2=33.
  • AV mute — blank the image and mute audio without powering down the lamp.
  • Status — lamp, filter, temperature and error state where the class exposes them.
  • Manual IP add — projectors rarely broadcast SSDP/mDNS, so a directed probe on 4352 and a manual IP field are both provided.

Set it up

1

Enable PJLink / network control on the projector

Find it in the projector's Network / Control menu. Set a PJLink password here too if the model requires Class 2 authentication.

2

Give the projector a stable IP

A DHCP reservation in your router is strongly recommended — ceiling-mounted gear is painful to re-address.

3

Install Remote97 on the same network

Get it from the download page.

4

Add by IP or let the scan find it

Remote97 probes port 4352 on the selected subnet. Then pick the input codes that match your model.

What PJLink cannot do

Lamp physics still apply. There is a warm-up delay after power-on and a cool-down lockout after power-off; commands sent during those windows are legitimately rejected. This is the projector, not the app.

Lens memory, motorised masking and calibration controls are vendor-specific and are not part of PJLink. If you need those, a serial-over-IP gateway with the projector's RS-232 command set is the usual route. PJLink also assumes the projector is on a reachable wired network — WiFi bridges with client isolation will break it.

Troubleshooting

  • No greeting string: PJLink is disabled, or a firewall is blocking TCP 4352.
  • Authentication error: the projector is in Class 2 mode and expects the configured password (MD5-based challenge).
  • Input command ignored: input numbers are model-specific — check the projector's PJLink input table.
  • Commands use LF instead of CR: PJLink is CR-only; a stray line feed makes the projector discard the frame.
