Media player

Control a Xiaoyi / Gaqingxiansheng 8K player from your phone

These 8K media players ship with a plain network control protocol. Remote97 implements it directly — and unlike a generic "WiFi remote", the button layout was verified against a real machine, not guessed from a manual.

6 min read · 小蚁 / 高清先生 8K · TCP 38091

小蚁 (Xiaoyi) and 高清先生 (Gaqingxiansheng / hdsir.net) 8K media players share one control protocol: a five-byte frame of # + a three-character command + \r, sent over TCP port 38091. A successful command is answered with #XXX OK\r; unsupported commands return !CMD Err\r. Remote97 uses that simple protocol for a full on-screen remote, no IR line-of-sight and no extra hardware.

What you can control

  • Power — a single power toggle button (see the honest note below).
  • D-pad and navigation — up, down, left, right, confirm, back, home, info, options and resolution.
  • Playback — play, pause, stop, fast forward, rewind, audio track and subtitle.
  • Volume — step up, step down and mute, confirmed against the real hardware (including the non-obvious volume-down code).
  • Verified button layout — the remote exposes only keys that were tested to work on a real player. Codes the hardware rejects are not shown as working buttons.

An honest limit: no status, toggle-only power

The firmware cannot report its state. There is no query command and no status push. Remote97 shows online/offline from connection reachability, and the power button is a pure "send toggle" action — it will not display a guessed on/off highlight that might be wrong.

On real hardware the three documented power codes (#PWD, #PON, #POF) all behave the same way: one press flips the machine's state. Because of that, Remote97 presents a single power button instead of promising separate on/off actions it cannot deliver. For the same reason there is no Now Playing screen, app list or track panel — the protocol simply has no data source for them.

Set it up

1

Note the player's IP address

Read it from the player's Settings → Network menu, or reserve an address for it in your router. The control port is TCP 38091.

2

Keep the player on the same subnet

The manufacturer protocol is not designed for cross-segment control. Phone and player should be on the same LAN.

3

Install Remote97

Get it from the download page.

4

Scan or add by IP

Remote97 can find the player with an active probe on 38091, or you can add it manually by IP. Then open its dedicated remote layout.

Troubleshooting

  • Not found by scanning: add it manually by IP — the player never broadcasts, and some networks block the probe.
  • Commands time out: the protocol expects one command at a time; wait for the response before the next press. Remote97 already spaces commands out.
  • A button appears dead: it may be a command this particular firmware does not implement. Remote97 hides codes known to be unsupported so the remote stays honest.
  • Want app shortcuts or track info: not available for this device — the firmware has no query interface.
