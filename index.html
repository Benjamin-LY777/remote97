Remote97 是一款纯软件的家庭影院遥控中心：无需中控主机，通过 WiFi 直接控制你的功放、电视、流媒体播放器，并把它们编排成一键场景。

免费下载 查看支持设备

核心能力

一个 App，控制整个影音室。

多品牌统一遥控

功放、电视、流媒体播放器集中在同一界面，告别一堆各自为战的遥控器。

一键场景

“观影模式”“K 歌模式”一键联动：关灯、开功放、切信号源、调音量自动完成。

纯局域网控制

设备指令全部走本地 WiFi（Telnet / HTTP / WebSocket / UPnP），不依赖云端，断网也能用。

自动发现

打开 App 即在后台发现同网段设备，省去手动配置 IP 的麻烦。

跨平台

Android、Windows、iOS、微软商店多端覆盖，随时随地控制。

持续扩展

已在路线图中规划 Roku、Yamaha、Sonos、Onkyo、Bluesound 等更多设备。
