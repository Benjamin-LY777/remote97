Remote97 は、お手持ちのスマホや PC をホームシアターの万能リモコンに変えるアプリです。ホーム Wi-Fi ネットワーク経由で機器と直接通信します — コントロールハブも、プロの設置工事も、月額料金も不要です。

## 特長

- **ハブ不要・ハードウェア追加不要** — すでに持っているデバイス上でアプリとして動作し、LAN 経由で機器に直接接続。
- **自動検索** — ネットワーク上の対応機器を自動で見つけます。IP アドレスの入力は不要。
- **ひとつのリモコンに集約** — 音量・入力切替・電源・サウンドモード・EQ・画面への文字入力をすべてひとつに。
- **マルチルームオーディオ** — Sonos・Bluesound（BluOS）・WiiM・Arylic スピーカーをグループ化し、複数部屋で同期再生。
- **自分好みにカスタマイズ** — ホーム / 部屋ごとにデバイスを整理。ガラス風や水墨風など複数の UI テーマを用意。
- **Windows グローバルホットキー対応** — 席を立たずにキーボードで全体を操作。
- **プライバシー第一** — クラウドなし・アカウント不要・テレメトリなし。すべてのデータはローカルネットワーク内に留まります。
- **無料。**
