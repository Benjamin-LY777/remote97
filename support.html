Remote97 支持中心

Support Center · 家庭影院 / 智能影音中控应用 · 中国区名称：影控中心

Remote97（影控中心）是一款独立的第三方影音中控应用，用于在局域网内集中控制您自有的电视、功放、播放器、投影机与音响系统。 它通过设备厂商提供的标准开放控制协议（如 UPnP / SSDP、Telnet、HTTP API、ECP、SSAP、PJLink、Yamaha YXC 等）与您自己的设备通信。

Remote97 is an independent third-party app. It is not affiliated with, endorsed by, or sponsored by any device manufacturer. Brand names (Denon, Marantz, Sony, Samsung, LG, Xiaomi, Apple TV, Roku, Yamaha, Sonos, etc.) are referenced only to indicate device compatibility.

快速开始 / Getting Started

1. 如何添加一台设备？ / How do I add a device?

  • 打开 App → 进入「设备」页 → 点击「添加设备」。
  • 选择设备类型（AV 功放 / 智能电视 / 流媒体 / 音响 / 投影机等），或直接使用自动发现。
  • 确保设备与手机在同一局域网，并已开启设备端的「网络控制 / 局域网遥控」设置。
  • 输入设备 IP（或使用自动发现），按提示完成首次配对。

Make sure the device and your phone are on the same Wi-Fi and that "network control / LAN remote" is enabled on the device. Enter the device IP or use auto-discovery.

  • 支持多种遥控面板样式：按钮式、滑条式、圆环式、双区式等，一键切换。
  • 组合环可分别绑定不同设备的音量（例如功放出声、电视屏显）。

Arrange controls freely on a flexible canvas — including the signature volume combo-ring. Resize, reposition and choose from multiple panel styles.

故障排查 / Troubleshooting

6. 找不到设备 / 连接被拒绝怎么办？ / Device not found or connection refused?

  • 确认手机与设备在同一子网（部分路由器开启了 AP 隔离会阻断通信，需在路由器后台关闭）。
  • 确认设备端已开启网络/局域网控制（不同品牌路径不同，详见 App 内「说明」按钮）。
  • 尝试手动填写设备 IP（可在路由器后台或设备网络信息中查看）。
  • 首次连接电视类设备时，请在电视屏幕上点击「允许」。
  • 若使用访客 Wi-Fi 或企业网络，设备间通信常被隔离，建议切换到家庭主网络。

Check AP isolation on your router, enable network control on the device, or add the device by IP manually. Guest/enterprise networks often block device-to-device traffic.

7. 连接不稳定 / 设备经常掉线？ / Unstable connection?

  • 让手机与设备尽量连接同一路由器的 5GHz 频段，减少中继/扩展器带来的延迟。
  • 在路由器后台为设备绑定静态 IP / DHCP 保留，避免 IP 变化导致失联。
  • 部分设备的「节能模式」会关闭网络待机，建议关闭该选项。

Prefer 5 GHz on the same router, reserve a static IP for the device, and disable the device's power-saving network sleep.
